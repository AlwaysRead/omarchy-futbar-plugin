# Issue #12079 follow-up review

The review covered remote JSON and image helpers, cross-process scheduling,
QML process lifetimes, collection loops, text/image/external-link sinks,
statistics transformations, fixture merging, preferences and notification state.
This was a targeted source review with regression and runtime checks, not an
independent security audit or exhaustive interactive coverage.

## Fixes

- Standings reject non-array groups, entries and statistics. Invalid responses
  preserve the previous table, report a parse error and clear loading. The shared
  JSON validator also rejects objects with a `length` key at every nesting level
  before any QML consumer receives them. This intentionally rejects otherwise
  legitimate provider objects using that key as well.
- The provider-controlled match-history season caption explicitly uses plain
  text, preventing Qt rich-text resource interpretation.
- Match details process at most two rosters of 64 players. Pitch placement
  rejects more than eleven starters before entering its quadratic collision
  solver. Malformed player entries are skipped.
- Penalty-score extraction bounds input and regex repetition so long digit
  runs cannot trigger excessive backtracking on the GUI thread.
- Scorer grouping uses a dictionary without a prototype, allowing names such
  as `constructor` or `__proto__` without colliding with inherited properties.
- Pass accuracy accepts ratios, percentages and formatted percent strings,
  preserves zero, rejects unsupported values and does not mutate input caches.
  Reusing a formatted cache no longer turns `86%` into `8600%`.
- Fixture-row merging compares all presentation fields, allowing refreshed
  names, crests, competition details, kickoff timestamps and series notes to
  replace stale values even when the score/status is unchanged.

## Regression checks

- The production standings callback runs under a JavaScript execution deadline
  against array-impostor payloads. The original callback times out on the
  reported payload; the corrected callback returns a recoverable error.
- Python tests reject nested array impostors and verify multi-response helper
  failures emit no partial output.
- JavaScript checks cover oversized pitch input, normal eleven-player layout,
  repeatable percentage formatting with frozen caches, inherited scorer names,
  long penalty notes and fixture presentation corrections.
- A real Qt runtime test exercises the production season-caption Text object
  with markup-shaped provider input and requires `Text.PlainText`.
- The full offline Qt/Wayland suite exercises plugin loading, profiles, keyboard
  navigation, cancellation, image decoding, scheduling and narrow layouts.
- Additional checks: JavaScript security/data suite, Python compilation,
  Omarchy manifest validation and whitespace validation. A live ESPN standings
  response with twenty entries passed the shared JSON validator.
